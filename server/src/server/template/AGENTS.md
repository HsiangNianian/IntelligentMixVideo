# 云端模板协作约定

适用于 `server/src/server/template/` 与仓库根目录的 `proto/`、Buf 配置，补充根目录与 `server/` 的 `AGENTS.md`。

模板编辑界面见 `client/src/features/templates/AGENTS.md`。

- 模板模块位于 `server/src/server/template/`，与用户示例目录 `sub_api/` 平级；路由、配置校验、数据库存储与效果目录均放在该模块内。
- 素材与数字人同屏配置保存为模板 `split_screen`（Protobuf/JSON 为 `splitScreen`），旧模板缺省关闭、旧客户端省略更新字段时保留；两窗口独立位置、尺寸、Contain/Cover、圆角、内边框和底色，数字人在上。仅 standard 命中区间同屏，其他区间全屏数字人，纯素材忽略；两窗口静音、保持原配音，数字人源时间连续，同屏停用两类转场。中英文字幕独立同屏位置，Remotion 跨界只切可见区间与宿主位置、不重置动画时钟。云端复用 ffprobe/Pillow/ZOS 准备几何图片，用 IMS mask_rec 圆角；SDK 5.2.2 通过媒体回调 `{url, maskUrl}` 及带几何的缓存键预览，`GET /template/preview-mask` 在线程池生成单帧 MP4（需 FFmpeg，32 项内存缓存，不接收用户视频）。SDK 图像装饰转 PNG，字体换行与合成保持一致；基础预览共用几何。配置与预览接口见 `server/README.md` 的模板接口章节。
- 标题和字幕分别保存 `tracks[].editor.titleFont` / `subtitleFont`，Protobuf 对应 `title_font` / `subtitle_font`。可选字体限定为 `server/src/server/template/fonts.json` 的十一项：前端与 Python 共用该目录，保存和合成使用 `value`，预览使用 `preview`。思源黑体由 `Source Han Sans CN` 转为 `Source Han Sans CN Normal`，思源宋体由 `Source Han Serif CN` 转为 `思源宋体`。缺少字段的旧模板默认 `Alibaba PuHuiTi`；重置只恢复当前对象的字体。未知字体、空值和 SDK 专用标识不能作为保存值。
- 新模板自动创建中文标题和中文字幕各一个，两者不可删除；前端提交与 Python 存储均强制检查中文标题和中文字幕各一个，创建和更新都适用，缺少时拒绝写入。VFX 最多一个，滤镜可添加多个。标题、字幕和 VFX 重复选择样式时替换已有对象的效果，保留参数。底部字幕从零持续到视频结束，时间不可修改。效果通过左侧「特效资产」添加，已添加列表用于选择对象。
- 模板保存结构中的 `tracks` 为必填数组，参数仅保存在 `tracks[].editor`。参数面板使用独立的 `EffectDraft` 临时视图。前端保存、详情读取及合成均校验完整规则，拒绝缺少 `tracks`、`tracks: null` 或携带顶层 `editor` 的模板，不提供旧格式转换。列表返回逐条校验的 `TemplateSummary`，无效记录保留 ID、名称、时间及 `validation_error`，主页禁止打开并提供单条删除确认；有效记录正常使用。无效记录详情返回 409。列表消息与转场字段要求客户端、服务端一起升级。
- 模板 `tracks` 也可以是 Remotion 片段：`target=remotion`，`sprite_id` 引用已发布 Sprite，`id` 在模板内唯一，同一 Sprite 可摆放多次。`start_mode=seconds`，`duration` 为 `null`（以发布预览长度为默认值）或正秒数，转场保留摆放时长。`editor` 只设置 `remotion`：`parameters` 每项恰好一个 `stringValue`/`numberValue`/`boolValue`/`stringListValue`；`transform` 包含内容中心 `x`/`y`、`scale` 0.25～4、`rotation` -180～180、`opacity` 0～1，滤镜与转场只能设 `opacity`。没有覆盖时返回 `{}`，IMS 对象不能设置它。没有 `content_box` 的已有发布只接受宿主变换，但字效的字体参数（`fontFamily` 与双栏的 `line1FontFamily`/`line2FontFamily`）例外：字体保存时按实时字体库而非发布时冻结的枚举校验（视频合成复核合并配置时同样如此），模板里仍可替换字体，其他未采样参数及其他分类的同名参数保持只读。覆盖须指向可编辑参数，类型、范围、枚举及合并结果符合发布 Schema，否则 422 并指明片段；其他对象不能带 `sprite_id`。所有片段引用已发布且画布宽、高、帧率一致的 Sprite，共用模板 100 条上限，不产生 `effect_ids`；保存仍要求标题和字幕各一个。片段按 `tracks` 顺序叠放。字效必须设 `text_target=title/subtitle`，每个文字对象最多一个，替代对应 IMS 文字，时间跟随该文字；`text`/`keywords` 由对象提供，禁止摆放覆盖，绑定时清除已有覆盖。转场必须设 `transition_boundary`，与 IMS 共用列表和选择方式；预览与合成均围绕素材连接位置居中计算，实际区间受相邻片段可用长度限制，保存保留原有时长。视频特效（含未指定分类的已有资产）与 IMS VFX 合计最多一个，滤镜可多个。分类不符、缺少或多余绑定字段返回 422。
- 云端模板库共享，不包含登录、用户隔离或旧数据迁移，配置存入 MySQL，使用 SQLAlchemy 和 PyMySQL。客户端（浏览器与桌面）只能新建和编辑云端模板：不提供本地模板入口、页签和「本地模板保存路径」设置，也没有 Tauri `local_templates` 命令；旧版写下的 `data/template/templates.json` 与 `$client.template_path` 留在磁盘，不读取、不删除、不迁移。连接失败、超时或服务端 5xx 时显示原因并保留草稿；切换模板复用未保存保护，目标读取失败保留原草稿。`$client` 由宿主按字段合并，通用表单只提交实际修改的字段。
- 云端模板保留 `GET /template`、`POST /template`、`GET /template/{template_id}`、`DELETE /template/{template_id}`；POST 请求使用 `application/x-protobuf`，列表、详情和保存成功响应默认在返回前经 `MessageToDict` 转换为 `application/json`（camelCase 字段、UTC RFC 3339 时间、保留空数组/映射及非 optional 默认值，未设置的 optional 字段省略），列表为 `{"templates":[...]}`，详情/保存为 `{"template":{...}}`，轨道仍为 `template.tracks.tracks`；旧客户端发送单一 `Accept: application/x-protobuf` 时保留二进制响应，其余请求默认 JSON（含省略 Accept 或 `*/*`），成功响应带 `Vary: Accept`；新客户端按 `Content-Type` 兼容两种格式，JSON 解析用 `ignoreUnknownFields: true` 容忍新增字段，删除仍返回 204 空响应。POST 无 ID 创建（201），有 ID 完整更新（200）；不存在的 ID 返回 404，不做 upsert。不存在独立的 Connect 路由。Buf 配置位于仓库根目录，TypeScript、Python 生成代码位于各自 `src/generated/imv/template/v1/`。
- 名称去除首尾空白后不能为空，MySQL 唯一约束拒绝重名（409）；保存校验数值范围、效果目录与动画互斥关系（422）。服务端生成 ID、UTC 时间和效果参数快照，不接受客户端渲染参数。
- 前端使用 SDK 5.2.2 的效果目录和静态动画 JSON，服务端维护同版本白名单；不提供 `/template/effects`。升级 SDK 时同步核对目录。修改 `proto/` 协议后运行 `buf lint`、`buf generate` 并提交 TypeScript 与 Python 的生成代码；已发布协议使用 `buf breaking` 检查兼容性。
- 模板保存兼容未填 `text_target` 但明确携带 `editor.remotion.businessTarget=title/subtitle` 的旧字效轨道，替换资产时保留两套文字共存；仍校验发布资产、画布、参数及禁止正文/关键词覆盖；标题/字幕用途只属于字效，非字效资产携带时保存返回 422。新 `text_target` 保持 IMS 替代规则，客户端读取旧轨道不自动补写，右侧说明两套文字共存，显式重选作用对象才采用新槽位。
