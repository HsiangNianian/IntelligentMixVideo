# 视频合成协作约定

适用于 `server/src/server/video_composition/`，补充根目录与 `server/` 的 `AGENTS.md`。

操练场界面见 `client/src/features/video_composition/AGENTS.md`；Remotion 叠加渲染见 `server/src/server/remotion_templates/AGENTS.md`；文案切片见 `server/src/server/segmentation/AGENTS.md`。

- 视频合成有字幕文案时，ASR 前按冻结模板计算 `max(1, 最小单行全角字容量 - 2)`，作为唯一字数上限传给切片 `max_segment_chars`。只按模板中文字幕对象估算：居中位置到较近画布边缘的两倍宽度除以正文/关键词较大字号（云端字体/花字按一 em 全角字）；Remotion 字效替代或叠加字幕时同样按该对象估算，不在浏览器里实测，实际放不下由成片排版预检缩小字号。容量随任务保存，恢复复用；标题、英文译文和操练场已有切片不重切，实际关键词及长串仍走成片排版预检。无法容纳一字时在 template 阶段以 `subtitle_capacity_too_small` 失败，不产生 ASR/模型调用。独立切片不传上限仍为 8。
- 数字人效果独立保存为模板 `avatar_effects`（Protobuf/JSON 为 `avatarEffects`），默认关闭，旧客户端省略重存保留。开场和圆形头像共用 FFmpeg 按显示方向/SAR 抽最多 8 帧、随包 OpenCV YuNet 定位的固定圆；任务 `avatar_opening` 保存定位或明确无脸，恢复复用。仅头像时 `duration=0`、不上传黑底；无脸跳过开场，头像回退有素材时只显示素材、无素材时显示原数字人，字幕普通位置；读取/检测故障仍报错。有效开场以黑底与 IMS `mask_circle` 覆盖前 T 秒，不拆素材或改变源进度，文字用普通位置；之后恢复对应区间布局，Remotion 只切可见范围、不改时钟。`splitScreen.layout` 默认 `split`（原分区窗口），新增 `overlay`（全屏完整素材叠人物）与 `circle`（全屏完整素材叠自动圆形头像），旧客户端缺失 layout 重存保留。后两者素材 Contain+模糊填充、不裁剪、不用素材装饰，人物 X/Y/宽高相对画布；圆头像通过 Crop 截头部正方形、mask_circle 放入窗口内最大正圆，保留圆内背景，不抠像。仅非圆形且实际同屏的数字人可用 IMS `AI_RealMatting`（北京/上海/杭州）；人物叠加默认开启，可关掉保留背景，无独立画中画选项，叠加无矩形装饰。三种布局都只在 standard 命中素材时生效，无素材恢复完整原数字人；字幕由模板手动摆放。SDK 仅配置和布局示意，圆头像预览居中裁切；纯素材忽略所有数字人效果。模型位于 `video_composition/models/`，部署随 wheel；来源、版本与完整第三方许可声明见 `server/README.md`。
- 视频合成 `processRules.videoDuration` 仅接受 JSON 有限正数，允许整数和小数；布尔值与数字字符串返回 422，不创建任务。无语音纯素材模式必填，其他模式可省略或为 null。
- 视频合成新请求先检查 `text`／`copy`：缺省、null、空串和纯空白视为空，同时非空或有非空文案却没有顶层 `audioUrl` 均返回 422。非空 `text` 为数字人模式（必需 `videoUrl`）；无非空 `text` 且有配音为纯素材有声，`copy` 可省略以不生成字幕；无配音且无文案为纯素材无声。`videoUrl` 和背景音乐不参与分流；数字人省略 `materials` 为纯数字人，显式数组走匹配，纯素材必须非空数组。服务端判定的内部模式保存在现有 MySQL `video_compositions` 表的 `data.request.compositionMode`，调用方不能指定；`copy` 合并成 `text` 前已判定，后续经 `CompositionRequest.from_snapshot` 读取保存值，没有模式字段的旧任务仍用原 URL 规则恢复，不按新规则重判。
- 视频合成新任务在 IMS 渲染后将临时源地址的内容转存至 ZOS `imv/video_composition/{task_id}.mp4`，并通过服务端 FFmpeg 从同一成片按解码顺序截取第 3 帧，上传同名 `.png`；只给这两个对象设置 `public-read`，核对大小和匿名读取后才保存成功。图片 URL 可按 `ZOS_WEB_URL` 和对象 key 拼出，不进入 GET 或回调；两者仍只返回视频的持久化地址。旧成功任务不迁移或补图。ZOS 凭据只读服务端环境，不进入客户端配置头或任务快照；转存失败不能返回 IMS 临时直链作为成功结果。
- 视频合成执行日志实现位于 `execution_log.py`（归类、引用、脱敏、文件写入与容量清理），新事件直接生成七模块内容，保存到以后端包 `server/src/server` 为相对根目录的 `.log/video_composition/<task_id>/`，七文件为 `request/template/asr/segmentation/matching/timeline/zos.json`，各自统一 `input/output/execute_log/error_log`。不再创建、读写或迁移数据库日志表和备份表，已有表不自动删除；业务任务表保留。重复正文以同任务七文件组成的对象为根使用 JSON Pointer `$log_ref`，上游输出优先保留，追加前展开、排序后重建引用；执行记录仅 `time/action/status`，错误单独保存，凭证继续脱敏。任务级、查询与通知归 request，素材匹配回调归 matching.output；最终提交请求的 timeline 归 timeline 输出，materials、packRules 原文展示且父对象不整块引用。渲染、取址与转存归 zos，zos.output 仅保存去重后的 aliyun_video_url、zos_video_url 原文和实际签名。业务事务提交后只将独立日志快照入队，单个后台线程顺序写入，时间取入队时刻；队列上限 128 条，满时提交线程等空位，不丢记录。
- `video_composition` 从同一份模板的 `remotion` 轨道固定 MySQL 资产快照，新模板使用上游 `text_target`／`transition_boundary` 槽位，旧 `editor.remotion.businessTarget` 保留兼容，新字段优先。新标题按所绑定对象区间，旧用途标题按摆放区间，字幕按切片正文与时间注入；运营参数和 HostLayer 变换保留。业务参数解析仅位于 `video_composition/remotion_content.py`，读取已发布资产契约，不修改 Agent 生成或发布流程；上游固定时长资产仅在合成侧通过 `remotion_timing.py` / `remotion-timing.mjs` 映射完整播放时钟到实际字幕区间，1～2 帧取发布静态帧或中间帧，已有动态声明资产继续直接接收实际帧数。渲染前在共享名额内做与叠加渲染相同的排版预检（测量实际渲染的源码，含固定时钟包装；在资产自己的画布上排版，按 cover 缩放后成片里看得到的部分判断是否出画布），放不下的标题、字幕缩小 `fontSize`，缩到最小仍放不下以 `remotion_text_too_long` 失败；英文标题和字幕的单行字效另缩到仍能单行显示的最大字号（缩到最小仍换行则保留整段放得下的字号，尽力单行，不因此失败），避免译文换行压到另一语言的文字；启用英文字幕时，字幕轨的单行字效换行后朝远离另一语言的方向展开：英文字幕向下、中文字幕向上，各自靠近另一语言的一行位置不变，空间足够时两条字幕因此不会互相压住，空间不足时移动会被裁剪、边缘处仍可能接近，旋转的字幕保持原布局，没有启用英文字幕时中文字幕保持原本的居中展开；这次渲染的摆放按实测的单行位置移动（居中排布时约为多出行高的一半），且不移出成片可见的画布（不改保存的摆放）。整段透明 WebM 从 0 秒直接加入 IMS 最后视频轨，新文字槽位沿用上游的 IMS 替代规则，实际输出的 IMS 文字在上层；上传结果持久化供恢复，源码不进执行日志。Remotion Agent、组合器、校验、发布与编辑预览以 upstream/dev 为准；仅保留 Chrome 多进程配置及视频合成所需渲染适配，后续修改等待用户真实测试反馈。新旧资产与测试说明见 `docs/remotion-video-composition.md`。
- 合成侧 Remotion 计划、时长适配打包、渲染或上传失败在清理前私有保存 `composition-overlay-failures/<task_id>/worker.log` 与完整异常链 `error.log`（附子进程 stderr；位于 Remotion 数据目录，任务诊断目录权限 0700）；公开七模块日志、GET 与回调仍只保留安全摘要，七模块日志另记根因的异常类型、代码位置与错误码，不含其文本。诊断写入失败不覆盖原任务错误，视频及编译目录照常清理。
- 操练场：`POST /api/v1/video-compositions/playground`（`mode`、`styleId`）读取随包 `playground_samples/{mode}.json`，缺失返回 409，目前只有 IP口播样本。样本只含可复用的准备结果（输入、时长、中英切片与提词、匹配、素材时长），不含回调、凭据或渲染结果；受理时重新固定模板与 Remotion 快照、跳过内容准备，之后与普通合成共用 Timeline、Remotion、IMS 与 GET 查询（IMS 完成后 GET 显示 `uploading`，不改持久化阶段），成品存 ZOS `imv/playground/`。共享 ZOS S3 客户端遵循 `HTTP(S)_PROXY`/`NO_PROXY`，大文件串行分片上传，保持 TLS 校验。
