# 界面手写字体

`imv-hand.woff2` 来源于 [悠哉 Regular v0.868](https://github.com/lxgw/yozai-font/releases/tag/v0.868)，曾用于界面文案；当前界面优先使用微软雅黑，保留此文件作为历史字体资产。

原始文件 `Yozai-Regular.ttf` 的 SHA-256：`25071998a0fe6a72f54c235e714986d259633e5ff670b1a2b5e264387f3316ac`。使用 FontTools 转为 WOFF2，未修改字形、字重或字符集。按 OFL 保留名称条款，将 name 表的 1/4/16 项改为 `IMV Hand`、6 项改为 `IMVHand`、3 项改为 `IMV Hand 0.868`；版权与许可字段保持原样，完整许可见 [OFL.txt](OFL.txt)。该文件为第三方字体的格式转换产物，不作手工二进制编辑。
