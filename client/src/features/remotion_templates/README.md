# Remotion 客户端

新生成使用三层 ReAct 执行 `preset.create → sprite.compose → sprite.create`，最终交付为保存后的组合 Sprite。
本链路主画布固定为 1080×1920、30 FPS，界面只显示说明，不提供画布尺寸、帧率或 Sprite 类型选项。
新会话在输入框下方提供「预览时长」（只决定生成与预览的长度，字效的最终时长由合成时总线传入的渲染时长决定）：常用 3/5/8/10/15 秒或自定义（四舍五入到整帧后须为 1 帧～30 秒，与服务端契约一致，输入框不设原生 min/max，空输入时说明范围，范围外或无法解析时提示错误并禁止发送，按钮与 Enter 一致），默认 5 秒，首次请求携带所选帧数，创建后固定；首个成功版本恰好是所选时长（服务端拒绝其他时长的组合），之后的修改以已验收版本为基础、总时长由实例编排决定，成功后及恢复历史时显示实际配置。
新会话另有「关键词字效」「双栏」开关（默认关闭）：打开时首次请求分别携带 `keyword_effect: true`、`two_tier: true`，新作品必须给命中的关键词生成自己的字效、必须是上下两栏的字效（服务端拒绝不符合的结果并交 Agent 修复），没打开时 Agent 仍按描述与参考图判断；创建后与预览时长一同隐藏。关键词为空时，预览（`model.ts` 的 `sampleKeywords`）以文字块标出的示例关键词 `preview_keywords`（仍在当前文字里的）为示例关键词；没有标出时，带关键词字效的版本（有以 `keywordEffect` 开头的参数）在 `keywordEffect` 开关未关时以当前文字首个非空行开头至多两个字为示例（文字未改时即默认文字，与生成校验挂载的示例相同），并在播放器下方说明，参数与保存不受影响；模板里只能填关键词与开关六个样式，关键词字效回到这里修改后重新保存到资产。
每条消息最多附 4 张参考图（点「图片」可多选、拖入输入区或 Ctrl/⌘+V 粘贴，一次可多张，超出 4 张的提示上限并只保留前面的；每张可单独移除；粘贴只截获图片，文字照常输入），发送时按顺序逐张 `POST /assets` 上传（整条失败时已上传的由服务端过期回收），再随创建或 `messages` 请求提交，开始对话后与回答澄清问题时同样可用；上传失败时服务端尚无写入，撤回本地消息、把文字和图片放回输入框并显示普通错误，不进入「刷新任务」读取恢复（输入框已有新内容时保留新内容）；输入锁定（任务进行中、会话恢复或删除中、查看历史版本、参数未保存、预览加载、服务未就绪）时不附图，输入区下方说明原因与何时恢复。
需要其他规格时新增会话；这不代表生成的代码已通过其他尺寸、帧率或时长的适配验收。
成功版本 `spec.schema_version=2` 保存组合 Sprite。代码只是确定的样例：参数面板按 Schema 生成类型化控件
（`components/ParameterControl.tsx`：颜色、带范围的滑条、枚举下拉、开关、限长文字与关键词）。文字组合的字效（`spec.sprite.text`）分为两块
（`model.ts` 的 `textSections`）：「文字」是文字本身——内容、字号、字体与字重、双栏排版、绑定在各栏上的颜色、描边、字间距等外观、关键词选项，
以及各栏 Preset 的内部参数（可展开的「正文」「上栏」「下栏」）；「特效」每个特效一张卡片，标题旁的开关决定是否应用（`effect{k}`），
卡片里是作用位置（`effect{k}Target`：整体、各栏、上栏、下栏或关键词）、入场与出场时长（`effect{k}Seconds`）、绑定在这个特效上的样式参数与它的内部参数，
关键词字效（关键词 Preset，开关为 `keywordEffect`）也是一张卡片；顶层参数按 `spec.sprite.bindings` 的绑定目标归入各栏或特效。模板编辑「外观与位置」的「特效」里按摆放调整
开关、位置与时长（`sprites/parameters.ts` 的 `EFFECT_PARAMETER`）。其他组合版本的顶层参数分为「配置」（宿主固定名称与标题的参数，`CONFIG_PARAMETERS`）
与「样式」，另有各实例的内部参数（「实例 · id」），无法逐项编辑的实例回退为 JSON 文本域。
超出范围、长度或项数的输入与非法 JSON 不进入预览并阻止保存；保存只提交净变化，服务端只做 Schema 校验并立即生成新版本，不再排队渲染。
嵌套对象递归合并，数组、标量和 null 整体替换。撤销恢复成功参数，历史预览保持只读。

字效的 `fontFamily` 参数（以及双栏字效每栏的字体 `line1FontFamily`/`line2FontFamily`）使用字体选择器（`features/fonts/FontPicker.tsx`，由 `ParameterControl` 对这些参数名自动采用，聊天参数面板与模板编辑的「外观与位置」共用）：选项来自共享字体库（`GET /api/templates/fonts`，预装与用户上传的字体，不是生成时冻结的枚举），每项用服务端预览条以字体自己的样子展示（CSS mask 随主题着色），可按名称或风格搜索；浮层底部可上传自己的 .ttf/.otf（`POST /api/templates/fonts`）：浏览器先从字体的 name 表读出显示名（优先中文名，不用文件名，规则与服务端一致，见 `features/fonts/names.ts`），用该字体画出预览条，同时验证文件可读，再与文件、名称一起上传，成功后立即选中，失败原因（文件已在库里、格式、大小）留在浮层里。左侧导航另有「字体库」页面（`features/fonts/FontLibrary.tsx`）：以卡片列出库内全部字体（一张卡片是一个家族，含常规、粗体、斜体、粗斜体中已有的字形；预览条、家族名、风格、来源、已有字形、大小），点击卡片打开字体详情（`features/fonts/FontDetails.tsx`，各字形的预览条、字重、大小与 SHA-256，缺少的字形标为未上传；点击已有的字形打开它的字样 `FontSpecimen.tsx`，用该字形的字体文件排出标题、字母数字、中文与可改示例句的字号阶梯），可搜索，也可直接上传字体（同一家族的粗体、斜体文件自动归入同一张卡片；库里已有同一个文件时直接选用、不再上传，上传请求失败后重新读取字体库核对，服务端其实已登记时按已在库里处理）；页面每次打开都重新读取字体库。Agent 按参考图从字体库里选一个作为默认字体，用户可在这里改选；选择保存在模板轨道的 `editor.remotion.parameters`。没有 `fontFamily` 的旧字效不显示字体选择。
模型只通过服务端调用，聊天仍使用 `/api/templates` API 和作品级 SSE。
新结果交付 Export.tsx 与隔离 Player；代码、参数与时长由服务端封存，参数修订复用原播放器包，预览页注入该版本的默认值。
预览背景可粘贴视频直链，也可「加载本地文件」（只在页面内以 blob URL 播放，不上传、不保存，桌面重启后需重新选择）；尚无字效版本时也能播放。背景由客户端底层 `<video>` 静音循环，先读元数据再调用 `play()`（Linux WebKitGTK 直接自动播放较大本地 blob 会解码失败），与字效的播放进度独立；上层版本播放器用 `?overlay=true` 透明显示，复用原封存包。背景视频不进入 iframe、Agent 请求或导出源码。

旧版本继续显示原画布与扁平控件。工作区右上角「保存资产」保存当前预览版本（唯一的保存入口）：分类取该版本聊天卡片上的分类下拉，默认为 Agent 判断的分类（字效、滤镜、视频特效、转场），可以改选，再调用 `POST /api/sprites/publish`；
本会话保存过资产时，保存按钮旁另有「保存方式」，默认覆盖该资产（按目录条目的来源版本匹配，沿用目标的类型与画布），也可以切换为另存为新资产；为版本改选其他分类时覆盖不可用，只能另存。 保存处可填写资产名称（去除首尾空白后最多 100 字符）：首次保存留空使用 AI 名称，覆盖或重复保存留空保留资产现名；填写后名称与发布内容一起保存。工作区订阅共享资产目录变化，并在窗口重新聚焦时补读，模板编辑处的重命名立即反映到覆盖选项与名称提示，后台刷新不清除未保存的名称草稿；目录读取失败先重试，不退化为新建。
字效固定发布 `text` 字段，版本声明了关键词参数时同时发布 `keywords`。服务端先渲染参数边界样本（请求最长等待 180 秒），所选分类缺少必备参数或版本早于分类时显示服务端原因；
相同版本重复保存返回原资产；覆盖同一版本时只刷新预览，不重复抽样。覆盖不能删除或隐藏已有可编辑参数、改成不兼容类型、收紧范围/枚举/长度/列表项数；无法确认兼容的跨参数约束也须另存为新资产，服务端在写入前返回 422 并保留原资产。旧版本重复保存期间若资产已被新版覆盖，返回 409，请刷新后重试或另存。资产代码固定，参数在模板里按每次摆放修改：在云端模板编辑左侧「AI 资产」按分类（字效、滤镜、转场与视频特效）点击卡片添加。
片段并入时间轴对应的文字、转场、VFX 或滤镜行，同类非文字片段重叠时另起一行；时间轴不支持拖动片段起点。新增摆放以发布预览长度初始化，字效区间跟随所绑定文字，转场按统一候选列表计算显示区间。右侧列出名称与时间，点选后在「AI 资产设置」调整本次摆放：
字效开放排版、关键词样式、特效开关/作用位置/时长及水平、垂直位置；滤镜与转场仅开放强度，视频特效开放位置、缩放、旋转和不透明度。字效时间跟随文字，只有中文标题可修改时间；滤镜和视频特效可在右侧改起点。其余参数在字效工作区修改，已有覆盖仍生效并可逐项恢复默认，片段可以移除；选中的可移动资产也能在预览画面上拖动或用方向键移动。
摆放是云端模板里的 `remotion` 轨道，随「保存模板」一次请求原子保存；保存时资产必须已发布，否则提示原因并保留修改；同一资产可以重复添加。
覆盖资产后，目录的 `sourceVersionId` 同时驱动封面与已打开模板的叠加预览重载（地址带 `version`），重置握手、旧能力与失败状态，再发送当前摆放的参数、宿主变换和时间；单纯改名不重载。版本号仅用于预览刷新，不写进模板轨道。
目录卡片与「特效资产」共用 `AssetBrowser`（搜索、卡片网格、分批显示），分类切换沿用 Remotion 自己的分类，不并入 IMS 特效列表；封面不新增服务端产物，由 `SpriteCover` 在前端定格：卡片进入视口才加载该资产的 `GET /api/sprites/{id}/preview?sync=1&fonts=host` 隔离播放器（字体由宿主页面经 `features/sprites/previewFonts.ts` 读取一次后转交，沙箱页不能使用 HTTP 缓存），经 `imv-preview-sync` 定位到资产时长 50% 处作静止封面，悬停或聚焦时依次轮播 20%、80% 处（要求减少动态效果时不轮播），离开视口即卸载；旧版本不支持 `sync` 的资产显示「暂无封面」，预览页报错或 15 秒未就绪显示「封面加载失败」。
资产卡片右上角的铅笔按钮重命名资产（`POST /api/sprites/{id}/rename`，任何人可改，去除首尾空白后 1～100 个字符、不要求唯一）；正被模板使用的资产也可以改名，失败原因留在弹窗里，成功后刷新目录，卡片、已添加片段与时间轴标签随之更新。资产目录里的删除按钮对当前草稿（含尚未保存的添加）摆放的资产禁用，并说明移除片段后才能删除；删除失败时重新读取目录核对：资产已不在目录里（超时、断线或服务端删完后才出错）或返回 404 都视为删除完成并关闭弹窗，仍在才把原因留在弹窗。资产库共享，目录在展开资产区时读取，在用期间订阅 `GET /api/sprites/stream`（`watchCatalog`，原生 EventSource），任何人保存、改名或删除资产后收到 `catalog.changed` 即重新读取；45 秒收不到 ping 或变化就换一条新连接，重连后的首条事件补读断线期间的变化；代理挡住推送时，窗口重新聚焦也会重新读取。模板预览使用阿里云 SDK，Remotion 资产画面由叠在上面的透明隔离播放器按模板预览的统一播放时间逐帧显示（IMS 就绪时由 SDK 推进，降级后由基础视频推进，二者未就绪时由前端时钟推进；保存资产或首次预览时尝试更新旧播放器包，重建失败时仍可使用已有旧包，能否叠加及显示参数覆盖取决于其 `sync`/`host` 能力），
多行字效（版本声明 `lineStartFrames`，目录摘要 `line_count` 为 2～4；新生成的只有双栏：上栏、下栏的字体、字重与字号比例是宿主固定的配置参数，颜色是样式参数，只在本工作区修改；字体、字重与字号比例和字号、栏间距一样也可在模板里按摆放调整）的文字按行编辑：聊天参数面板的 `text` 显示 N 个逐行输入框（`ParameterControl` 的 `lines`，用换行连接，任意一行为空不进入预览），`lineStartFrames` 由宿主按字幕切片注入、不在面板显示，行间距 `lineGap` 是普通参数，在模板里也和字号一样按摆放调整；模板里作用于底部字幕时示例文字同样逐行填写并写回字幕对象，作用于标题时同样逐行填写并写回标题对象（合成时实际标题按其中的换行分行，没有换行时整段显示在第一行）。预览按资产默认的行起点逐行出现。
字效工作区不直接发起整片合成；整个模板的叠加视频由服务端 `POST /api/v1/overlay-renders` 提供给总线。
会话切换、新增、历史预览继续使用保存/放弃/取消保护，取消请求由服务端持久化后停止工作。

聊天历史只保存在使用者本地：`localSessions.ts` 定义会话存储接口，桌面通过 Tauri `remotion_sessions` 异步命令读写应用数据目录的
`data/remotion/sessions.sqlite3`（读写不占用界面线程，进程共用一个连接，表结构按 `PRAGMA user_version` 版本化；
IPC 参数结构固定在 `client/tests/remotion-sessions-contract.json`，前端测试逐字比对、Rust 测试执行同一份夹具），浏览器保存在当前站点的 IndexedDB `imv-remotion-sessions`（表结构与桌面库对应，事务以 strict 持久性落盘后才算完成，刷新或重启浏览器后仍在；连接被浏览器关闭或其他页签删除本库后，下次读写重新打开；清除站点数据后记住的会话已不在本机，静默回到空白页）。会话按当前 API 服务地址归属（设置里改了共享后端地址后，侧栏只列该服务的会话，删除也只移除该服务下的本地记录）。
库里另存全局唯一的本机设备 ID，所有 Remotion 请求
与 SSE 以 `X-IMV-Device` 携带，服务端只返回本设备的作品。会话订阅把每个事件先写入本地再调用 `POST /works/{id}/ack`
确认送达，服务端随即删除已送达事件；重新连接时从本地游标续传并补发一次确认。只有打开的会话有 SSE：其余仍在排队或运行的
本地会话由 `backgroundSync.ts` 在工作区挂载时与之后每 30 秒通过 `GET /works/{id}/events?after=` 分页拉取到取空，按同样的规则
写入本地并确认，侧栏随之更新（否则后台任务会一直显示“正在处理”，其回复与版本指针在服务端 7 天后过期丢失）；服务端答复
404/410 时同样标为已删除。本机最新任务仍显示排队或运行、而服务端没有事件可送时（长时间离线后事件已过期，或确认丢失），会话打开、后台同步挂载后的第一轮与「停止」各读取一次任务当前状态（`GET /jobs/{id}`，停止用取消回执）并校正本地任务状态与成功版本指针（`settleJob`、`local.reconcile`），已过期的消息不会补回，会话不再被锁在运行中。同一会话的本地读写按调用顺序串行，SSE 正在订阅的会话由后台同步跳过（写入前在队列里再次检查）。本地库读写失败时不当作断线重连：
订阅停止，显示 Rust 返回的原因与「刷新任务」，服务端保留未确认的事件，修复后刷新即续传。新作品创建成功但本地登记失败时，
客户端先 `DELETE` 刚创建的作品（取消其任务），再显示本地错误并把文字和图片放回输入框，避免本机看不到的作品与重复生成；
侧栏标题按码位截取前 40 个字符，不会截出半个 emoji。侧栏、消息分页与恢复都读取本地库，
删除会话先由服务端清理再删除本地记录（服务端要停止任务并逐个版本清理对象存储，删除请求最长等待 120 秒而不是普通的 20 秒；失败时弹窗附上具体原因，如超时、服务端说明或本地库错误）；服务端报告会话不存在或正在清理（404/410）时，本地记录在侧栏标为
「已删除或正在清理 · 可重试删除」且不能再打开，重试删除成功后才删除。本机库丢失后无法找回聊天，服务端数据在设备不活跃 90 天后清理。

任务消息下方另有一块可折叠的「循环记录」：按轮列出宿主实际执行的工具与结论
（工具名、成功或失败，失败时带白名单错误码与宿主固定说明）。每个调用行只显示工具名与模型给出的参数（单行 key=value 摘要），点开看原始 tool call
（名称与参数 JSON，失败时附错误码与工具的真实错误）；没有调用的轮次显示模型回复或失败原因。
参数与错误说明是有意公开的审计内容，可含计划步骤目标、候选源码或服务端路径，不会再做脱敏。
参数由服务端截断后发布（完整内容留在私有审计），截断后不再是合法 JSON，摘要与原始 tool call 按原文显示；
旧记录没有参数，调用行只显示工具名。
运行中默认展开记录与最新一轮，任务结束后收起，没有记录的旧任务不渲染该区域。
本地会话保存完整轮次，`job.round` 事件逐条写入并去重；`job.updated` 不重复发送轮次，
客户端在状态更新时保留已收到的记录。无效模型协议轮次明确显示失败原因。

服务端以 503 拒绝请求时，若 `detail` 是文本则原样显示（例如非 Linux 服务端缺少隔离校验环境），否则显示通用的“服务尚未就绪”；创建、消息与重试在入队前被 503 拒绝时任务并不存在，因此不再追加“检查历史会话”的提示。

展开版本卡片的代码时同时读取 `GET /versions/{id}/diagnostics`：代码按行着色并标注
error/warning 行，诊断清单点击可跳到对应行。高亮是 `codeHighlight.ts` 的展示用近似分词，
只影响颜色，不参与验收；真实结论只用服务端隔离类型检查返回的诊断。诊断读取失败时
代码仍可查看，并提供显式「重试诊断」；未保存参数等禁用状态下不发起诊断请求。
