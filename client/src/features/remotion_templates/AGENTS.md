# 字效工作区协作约定

适用于 `client/src/features/remotion_templates/`，补充根目录与 `client/` 的 `AGENTS.md`。界面、本地存储与开发联调的说明见本目录 README。

服务端字效生成、发布与渲染见 `server/src/server/remotion_templates/AGENTS.md`；会话删除、参考图校验与进度记录的服务端约定也在那里。

## 结构

- 复用 `VITE_API_URL`，请求前缀为 `/api/templates`；保留原模板库入口。
- 任务提交用 POST；公开消息、任务状态与成功版本指针都走作品级 SSE，不要恢复客户端任务轮询。
- 预览用无同源权限的 sandbox iframe 加载服务端隔离构建的 Player 包（连同带默认 props 的 `Export.tsx` 纳入产物清单）；消息检查来源、通道与请求编号，完成、失败、超时与卸载时都清理加载锁与资源。

## 新会话

- 生成前可选画布、时长与高级宽高/帧率，默认 1080×1920、30 FPS、5 秒。界面称「预览时长」：只决定生成与预览的长度，最终时长由总线渲染请求决定。秒数四舍五入到整帧，至少一帧、不超过 30 秒，尺寸遵循服务端边界。
- 首次请求显式携带 composition；「关键词字效」「双栏」「双语字幕」开关打开时才带 `keyword_effect: true`、`two_tier: true`、`bilingual: true`。同时开启双栏与双语表示两组中英字幕（四行），单独开启双语表示一组；参数面板按原文、译文各自的内容组数编辑。非法草稿禁止发送，上传与生成期间锁定。
- 创建后不改该会话的配置，新增会话恢复默认；历史展示成功版本的实际配置，不宣称代码已支持任意规格。

## 会话、版本与切换

- 布局：最左侧历史列表（顶部「新增聊天」），中间聊天，右侧上方预览、下方参数。桌面三栏可拖拽或用键盘调宽，本地保存尺寸并可恢复布局；窄屏用历史抽屉与聊天/预览切换。
- 成功版本在对应聊天结果下显示默认折叠的代码卡片，可单独复制 `Export.tsx`、单击预览；参数修订标注来源。失败候选与纯问答不产生版本卡片。
- 代码卡片展开时读取 `GET /api/templates/versions/{id}/diagnostics` 并按行标注 error/warning。`codeHighlight.ts` 的高亮只影响阅读颜色，不参与验收、不进入隔离预览。诊断读取失败只降级诊断区并提供显式重试，禁用状态下不发请求。
- 历史预览只读：不回滚服务端，也不改变编辑基线；回到最新版本才能调参与发送。SSE 新到的成功版本不抢走用户明确选中的历史预览。
- 新增、切换历史、断线与卸载都不取消后台任务；只有明确停止或确认删除会话才取消。
- 新增、切换会话或切换旧版本时遇到未保存参数，提供「保存并切换」「放弃修改并切换」「取消」；保存并取得成功版本后才切换，失败留在原会话。
- 迟到的结果不得回填到其他会话；网络错误不自动重复写入。
- 纯提问、问候或「保持现状」以 `answered` 终态结束，回答经 SSE 展示，不生成候选、不发布版本、不重载播放器；回答后可以继续制作。

## 预览与参数

- 预览背景可用视频直链或本地文件（只用页面内 blob URL，不上传、不保存，换背景或卸载时释放），不发给模型、不嵌入导出。背景由底层 `<video>` 先读元数据再静音循环播放（WebKitGTK 直接自动播放较大的 blob 会解码失败），与字效播放独立、不锁定操作。版本预览以 `overlay=true` 透明叠加，仍向封存的播放器包发送空 `background`。
- 生成、参数保存检查与预览首帧期间禁用发送、图片变更与参数控件；聊天文字可以保留草稿，正常播放不锁定。任务等待与播放器加载分开显示，只有播放器真正加载时才显示预览渲染遮罩。
- 本地参数草稿实时预览，不锁控件、不自动提交；显式保存时批量提交相对当前成功版本的净变化，撤销恢复上次成功的默认值。有未保存参数时禁止发送、改图与复制代码。
- 参数未保存、提交中或读取中时禁止普通恢复操作，UI 与会话 hook 同时守卫；本次保存响应未知或产物读取失败时只允许只读恢复，不自动重发写入。同一会话重复选择不清空草稿；StrictMode 重建订阅后仍要恢复历史。
- 参数保存失败时保留此前成功的代码与本地草稿，显式撤销才恢复默认参数。新版本产物读取失败单独提示并提供只读重试，旧结果保持可用，不阻塞后续 SSE，也不反复重放同一个失败事件。
- 参数面板（`model.ts` 的 `textSections`）：文字组合的字效分「文字」「特效」两块。「文字」是内容、字号、字体、排版、各栏外观、关键词选项与各栏（「正文」「上栏」「下栏」）的内部参数；「特效」每个特效一张卡片，标题旁的开关决定是否应用，卡片里是位置、时长、绑定在该特效上的样式与内部参数，关键词字效（开关 `keywordEffect`）也是一张卡片。其他版本仍分「配置」「样式」（`CONFIG_PARAMETERS`）。
- 关键词样式由云端模板按摆放设置：七个关键词参数的默认值必须保持关闭，否则版本无法保存到资产。面板在格式不合约（多为旧版本留下的默认值）时显示 `keywordDefaultProblem` 的说明；`saveParameters` 检查修订后的完整默认值，旧版本未改动但仍开启的关键词选项也必须恢复关闭（只影响保存，本地预览不受影响）。发布因此被拒时，警告横幅提供「让 Agent 修复」，发送固定的聊天指令（保留外观、七个关键词选项恢复关闭默认值）；历史预览不能发送，先回到最新版本。
- 自由组件版本（`spec.sprite.effect`，`model.ts` 的 `effectSections`）同样分「文字」「特效」：「文字」是宿主配置与分组为「文字」或未分组的样式参数，其余样式按 Agent 声明的分组（Schema 的 `x-imv-group`）各成一张卡片，组里第一个开关作卡片的应用开关，`keywordEffect` 放进「关键词字效」卡片；示例关键词取清单的 `text.keywords`。
- 模板编辑只开放排版参数与特效的开关、位置、时长（「外观与位置」里单列「特效」，关键词参数在「关键词设置」页签）；特效自己的外观属于样式，只在工作区修改。自由组件带分组的样式参数例外：发布时带 `group`，模板按分组成卡片逐次调整。
- 成功回复里的 `suggestions` 只在最新一条回复下显示为选项，点选即作为下一条指令发送，与输入框发送同样受任务锁约束。
- 关键词为空时，预览优先以文字块标出的 `preview_keywords`（仍在当前文字里的）为示例关键词，未标出时取当前文字开头至多两个字，并加说明；`text_fit` 的挂载不看 `preview_keywords`，仍取开头至多两个字。参数与保存不受影响。
- 「保存资产」的名称去除首尾空白后最多 100 字符：首次保存留空用 AI 名称，覆盖或重复保存留空保留现名，填写后与发布内容一起保存。工作区订阅共享资产目录并在窗口重新聚焦时补读，模板编辑处的改名立即反映到覆盖选项与名称提示；后台刷新不清除未保存的名称草稿；目录读取失败先重试，不退化为新建资产。

## 参考图

- 每条消息最多 4 张（点击、拖入或 Ctrl/⌘+V 粘贴，可一次多张），每张 PNG/JPEG/WebP 不超过 10 MiB，同一张不能重复列出。
- 首条随 `POST /works` 的 `images` 提交，之后随 `POST /works/{id}/messages` 的 `images` 提交（可以不带文字，不能与 `parameters` 同时提交；澄清回答沿用原任务的参考图）。`POST /works` 仍接受旧客户端的单张 `image`。
- 输入锁定时不附图，并在输入区下方说明原因与恢复时机。

## 本地会话存储

- 公开聊天、任务公开状态与本机设备 ID 只存在使用者本地；版本列表与代码按需从服务端读取，本地只记作品当前版本指针。不把模型滑动窗口当历史。服务端不提供会话快照与历史分页，侧栏与消息分页读本地库。
- 桌面：Tauri `remotion_sessions` 异步命令在阻塞线程池读写应用数据目录的 `data/remotion/sessions.sqlite3`（rusqlite bundled，进程共用一个首次调用时打开的连接，表结构按 `PRAGMA user_version` 建立与迁移）。各操作参数是固定结构，前端发送的参数与 `client/tests/remotion-sessions-contract.json` 逐字比对，Rust 测试执行同一夹具。
- 浏览器：当前站点的 IndexedDB `imv-remotion-sessions`，表结构与桌面库对应；事务以 strict 持久性落盘后才算完成，之后才确认送达。连接被浏览器关闭（如清除站点数据）或被其他页签删除、升级时放弃该连接，下次读写重新打开。
- 两种实现共用 `localSessions.ts` 的存储接口与事件合并规则。
- 会话、消息与任务按当前 API 服务地址（来源加路径，忽略大小写、默认端口与末尾斜杠）归属：切换服务后侧栏只列该服务的会话，删除只移除该服务下的本地记录；设备 ID 全局共用。
- 送达：按事件 ID 先写入本地，再 `POST /works/{id}/ack` 确认。SSE 从本地游标续传，重新连接时补发一次本地游标确认。
- 未打开、任务仍在排队或运行的本地会话由 `backgroundSync.ts` 在工作区挂载时与每 30 秒经 `GET /works/{id}/events?after=` 拉取（带设备头，按编号升序分页，取空为止），按同一规则写入与确认；跳过 SSE 正在订阅的会话，同一会话的本地读写串行。
- 本地库读写失败（Tauri 的字符串错误与 IndexedDB 错误都包装为 `LocalStoreError`）不当作断线重连：停止订阅，显示原因与「刷新任务」。
- `localStorage` 只存上次选择的会话 ID 与桌面栏宽偏好；记住的会话不在本地库时静默清除选择，不提示删除。

## 删除会话

- 用 `DELETE /api/templates/works/{id}` 整条删除，最长等 120 秒（`DELETE_TIMEOUT_MS`），失败提示附上具体原因；写请求不自动重发。服务端完成后客户端才删除本地记录。
- 收到 404/410 时把本地记录标为 `deleting`：侧栏显示「已删除或正在清理 · 可重试删除」且不能再打开，重试删除成功后才删除本地记录。后台同步遇到 404/410 同样处理；SSE 收到 `work.deleted` 或 404/410 时终止重连。
- 删除确认允许放弃当前草稿；删除当前会话后释放预览与订阅，删除其他会话不影响当前编辑。

## 处理时间线

- 任务消息下的处理时间线只记录宿主实际进入的阶段：阶段名是白名单，不从模型普通文本推断，不显示虚构的百分比或未来步骤。运行中默认展开，成功或回答后收起，失败或停止时保留最后阶段；计时器在终态与卸载时清理。
- 循环记录（`job.round`）的公开字段见服务端 README「Loop rounds」。前端每个调用行只显示工具名与参数摘要，点开看原始 tool call；运行中默认展开最新一轮，没有调用的轮次显示模型回复或失败原因。截断后的参数不再是合法 JSON，按原文显示。
- 客户端合并 `job.round` 并去重，普通 `job.updated` 与侧栏不重复携带累计记录，状态更新保留已收到的记录。本地会话快照 `jobs` 带当前消息页对应的任务链路，支持历史分页、刷新与 SSE 重连；没有记录的任务不补造阶段。
- 旧版后端 SQLite 里的会话、版本与文件不迁移、不再读取。
