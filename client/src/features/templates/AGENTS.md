# 模板编辑协作约定

适用于 `client/src/features/templates/`，补充根目录与 `client/` 的 `AGENTS.md`。

模板保存结构、字段与服务端校验见 `server/src/server/template/AGENTS.md`；Remotion 资产的发布、目录与预览接口见 `server/src/server/remotion_templates/AGENTS.md`；桌面预览媒体服务与 Windows localhost 页面服务见 `client/src-tauri/AGENTS.md`。

- 模板 API 请求集中在 `features/templates/api.ts`，SDK 加载与预览在独立模块，避免在纯展示组件中散落请求与错误处理。
- 前端资产列表通过 `isSelectableAsset` 排除 `CS0003-000002`；花字下拉框允许当前对象保留已选中的该花字及勾选标记，清除或更换后无法重新选择。完整效果目录保留该花字供已有模板读取、预览与保存。
- 侧栏编辑入口显示「模版编辑」，使用现有 Lucide `SquarePen` 图标；保留 `library` 内部标识和工作区状态，窄屏保留图标及无障碍名称。
- 主页内容最大宽度 1400px、整页滚动。顶部「开始创作」并排「新建云端模板」「AI 生成字效」（跳转 Remotion 字效）快捷卡片；下方「我的模板」只展示云端模板，标题带数量与刷新入口。模板以自动列数画廊卡片展示（最小约 210px，窄屏单列），封面按模板 ID 生成稳定配色并排版模板自身的标题 / 字幕文字，角标显示对象数，悬停显示「打开编辑」；名称、更新日期、单行说明与完整 `styleid`（模板 UUID）位于封面下方，点击卡片选择模板；每张卡片提供红色垃圾桶，确认框显示名称与 ID，确认才删除模板，取消不修改，失败保留确认框供重试；删除当前打开的模板后清空编辑区；删除正在读取的模板时取消对应请求、清除加载与错误状态并忽略迟到回执，其他草稿和读取保留；空列表提供新建入口。主页不展示更新日志，客户端各页头均不显示当前时间。复用 Button、Dialog 和表单组件，列表读取失败可重试。
- 标题、字幕各有「中英双语」开关，首次开启新增 `language=en` 的独立文字对象，`language` 省略为中文；同用途每种语言最多一个。英文外观和 Remotion 绑定独立，时间跟随中文（包括停用时），示例文字可编辑。关闭时 `enabled=false`，模板与资产引用保留，预览、翻译、合成及 Remotion 环境检查跳过该英文及其绑定，重新开启恢复设置；从未开启不创建英文对象，不新增数据库表。`video_composition` 在切片后调用现有 `translate`，英文逐片同步，标题取本次译文，翻译失败以 `translation_failed` 终止，翻译中断不重放成本调用；译文随任务快照恢复，不进入素材匹配。英文字幕及展示关键词复用中文字幕去标点规则，保留问号、数字内小数点、英文词内撇号和空格换行；英文标题和原始译文快照保留标点。普通 IMS 使用 `AdaptMode=AutoScale`、`TextWidth=0.9`，Web SDK 暂不支持缩放并在面板提示；Remotion 沿用资产契约与排版预检。客户端、服务端需一起升级。
- 三个预览视频各取前 10 秒（用户选择的本地文件使用完整时长），顺序固定且始终各占一条 track，视频片段不可拖动和调整长度；初始没有转场。选中转场对象或空转场 track 时，右侧展示「镜头转场」面板；默认及选择其他对象时隐藏。通过「＋ 添加转场」搜索选择效果，展示全部候选，统一设置开关、IMS 的 0.1～3 秒持续时间及「转场选择方式：顺序选择／随机选择」。`transition_enabled` 默认 true，关闭时保留候选但预览及正式合成都不应用转场；「镜头转场」track 始终存在，没有应用效果时为空。开启转场且存在候选时，预览在两个连接位置应用转场，只有一个候选时两处共用；有多个候选时，顺序选择列表前两项，随机每次从完整候选列表选择，允许连续重复，修改时长和其他对象保留本次随机结果。`transition_boundary` 为 IMS 与 Remotion 共用的候选序号（1～100），删除后连续编号；`transition_duration_seconds` 为 IMS 统一时长，默认 1 秒。Remotion 新增时将发布预览长度（`preview_frames / fps`，客户端 `seconds` 同源）写入显式 `duration`；读取、编辑和保存保留其值，已有空值以发布预览长度为默认值，显式时长优先且不受预览长度限制，最终仍按相邻镜头可用长度裁剪。前后端共用 `server/tests/transition_duration_cases.json` 验证这些规则。选择方式下方仅提示「预览仅示意效果」，按钮名称不变。`transition_mode=sequence` 在正式合成时按列表循环，`random` 每次从完整候选列表选择，同一候选不限使用次数，任务 ID 保证重试一致。未携带方式的已有模板在新任务中按顺序循环；升级前已受理的任务仍按原规则恢复。左右两侧均可添加转场，添加失败弹窗提示。 新合成任务按口播关键词所在字幕事件的开始时间，严格寻找之前与之后最近的切镜（同刻切镜跳过，2／5／8 秒切镜与 5 秒关键词选 2／8），去重后选择转场；有关键词的混剪只找数字人↔素材，纯素材找素材↔素材。整片无口播关键词才回退全部切镜，标题词和英文译文不参与。首尾缺一侧只用另一侧；过短的最近切镜跳过、不找更远处、不推进顺序候选。新任务在现有 JSON 数据中保存 `keyword_transitions=true`，旧任务缺标识则沿用原策略，以保持已有 Remotion 产物与恢复后的 IMS 时间线一致；两种渲染器复用 `video_composition/transitions.py`，不新增模型调用或数据库表。
- 对象时间表单的输入和选项变化立即更新内存中的模板草稿及预览，保存模板时才写入存储。非法输入保留当前有效规则并提示，保存前检查时间输入有效性；时间输入框回车不触发保存。
- 默认视频与用户填写的 URL 均由工作区读取真实时长和尺寸，读取失败可重试，完成前不计算预览时间。`resolveTemplate` / `resolve_template` 根据模板规则和 `TimelineContext` 返回总长、视频区间、对象区间与说明；预览、时间轴、右侧面板共用结果。预览采用 `centered`：视频连续排列，IMS 与 Remotion 转场均围绕连接位置居中，奇数帧时后半段多一帧，总时长保持不变。SDK 5.2.2 用前段末帧与后段首帧的图片转场覆盖居中区间，位于视频上方、滤镜与文字下方；补帧缓存随预览释放，读取失败明确提示。`sequence` 按帧累计扣除转场重叠；`fixed` 保留正式合成的素材时间和音频总长。转场最多使用相邻片段各自长度的一半，不足 0.1 秒或缺少连接位置时不应用并说明原因。视频信息由工作区独立持有，更换来源与修改转场只重算应用结果。对象开始支持秒数或百分比，持续时间支持固定秒数或持续到结束；结尾以外不显示，结束越界时截短，动画按可用帧数缩短并显示说明，帧数不足时明确报错。前后端共用 `server/tests/template_timing_cases.json` 和 `template_sequence_cases.json`。
- 阿里 SDK 预览下方使用 `@xzdarcy/react-timeline-editor`，从上到下显示标题、字幕、气泡、转场、VFX、滤镜、视频。视频固定显示在各自的 track，其他对象在右侧修改时间。组件使用独立编辑副本，轨道与时间调整说明由 `TemplatePreview` 按当前草稿用生成 SDK 时间线的同一个 `buildTimeline` 生成，不等 SDK 载入时间线，IMS 加载、卡住或出错时照常显示与更新。播放器按视频、滤镜、VFX、文字从下到上组装图层。普通对象保存 `id`、`target`、`start_mode`、`start`、`duration`、`editor`；IMS 转场保存 `id`、`target`、`transition_boundary`、`duration`、`editor`，禁止 `start` 和 `start_mode`；最多 100 个实例。标题、气泡、VFX、滤镜支持 `seconds` 或 `percent` 起点，百分比小于 100，`duration: null` 表示持续到结束。字幕固定 `seconds`、0、null。前端与云端校验对象数量、时间、分类、动画互斥与 ID 唯一性。播放位置由前端持有：IMS 就绪后由 SDK 帧事件推进，降级后由基础视频推进，二者都不可用（IMS 加载、应用修改中或失败）时由 `previewClock.ts` 的前端时钟按真实时间推进；换来源时新来源接着当前位置与播放状态。播放按钮、进度条、时间轴、文字选择框与 AI 资产只跟随这个位置，解析出时间就可用，不等 IMS。游标与数字时间最多每 0.1 秒更新一次（时间轴组件每次移动游标都会整体重渲染，与 SDK 共用主线程；暂停和播放结束时游标校准到播放器停下的时间），SDK 定位暂停播放，等待 `playerSeeked` 后允许继续；修改效果回到开头。缩略图使用有界缓存，取消和卸载释放资源。合成标题使用请求文字及模板时间，气泡使用模板文字和自身区间；字幕使用切片原文与时间，保留中英文问号及数字内部的小数点、去除其他标点，匹配请求仍使用原切片，已有 `subtitle_parts` 继续按短句合成。转场按列表方式选择，时长受相邻片段长度限制，音频总长保持不变。视频和图片使用 IMS `Contain`，比例不同时用 `Background/Blur` 填充留白。客户端核心测试包括 `transitions.test.ts`、`effect-tracks.test.ts`、`track-timing.test.tsx`、`preview-timeline.test.tsx` 和工作区测试；服务端覆盖模板保存与合成。
- 客户端读取到 `Draft.clips`，保存时追加为 `remotion` 轨道，SDK 本身不渲染这些资产。右侧只调整这次摆放适用的设置：字效为示例文字、排版参数（字号、字体、字重，双栏另有栏间距与逐栏字体、字重、字号比例）、水平和垂直位置（0～100%，存储为资产画布像素）、关键词与标题的时间，滤镜与转场为强度，视频特效为位置、缩放、旋转与不透明度；字效可改作用对象，滤镜和视频特效可改开始时间，转场在统一面板选择效果。颜色、速度、动画与出入场时间等资产内部参数显示于「资产默认参数」，提供字效工作区入口；这些参数与字效缩放、旋转、不透明度已有的覆盖继续生效并列出「已覆盖」，支持逐项恢复默认。选中被字效接管的标题或字幕时显示字效设置。时间轴字效使用对应文字行，点击该行选择字效；转场共用一行，其他片段并入同类 IMS 对象行，时间重叠时增加一行；可移动资产支持画面拖动和方向键。客户端与服务端需一起升级。
- 「重置特效设置」通过 `resetTextTarget` 清除当前标题、字幕或气泡的样式与动画，并从 `defaultEditor` 恢复示例文字、字号、位置和入出场时长；保留其他对象和模板信息，不修改输入草稿或共享默认配置。纯函数用例覆盖三个对象、重复重置和无效输入恢复，组件用例检查重置按钮更新草稿。
- 模板库采用资产、预览、参数三栏布局，顶部展示模板名称、描述和保存状态，并提供保存按钮。名称与描述旁的铅笔可切换为文本框，失焦时复用完整保存流程提交当前草稿（名称回车同样保存，Escape 取消本字段编辑）；未修改不写入，空白名称拒绝保存，失败保留草稿供修改或手动重试。模板选择与新建位于主页；新建名称必填、最多 100 个字符，描述最多 1000 个字符，进入编辑前去除首尾空白。尚未选择模板时展示前往主页入口，新模板也受未保存保护。工作区只读取目标详情，失败保留当前草稿并允许重试，卸载取消请求；首次保存创建记录，后续携带原 ID 更新。`EffectAssets` 按 SDK 分类展示真实目录封面并支持名称/编号搜索，文字效果显式选择作用对象；无封面或加载失败显示明确占位。`AppliedEffects` 从轨道实例生成对象列表，选择后由 `EffectEditor` 编辑独立参数；循环与入出场动画保持互斥，应用时按文字实际显示时间调整动画。移除对象只清除对应实例，其他对象不变。默认预览三个各十秒的竖屏视频，画布固定为成片的 1080×1920。窄屏按容器宽度重新排列，搜索回车不提交模板。模板测试使用随包真实目录，覆盖核心数据规则及必要组件行为，执行方式见客户端 README。
- 主页创建草稿不调用 POST；模板库保存时无 ID 创建、有 ID 更新。未保存切换须提供保存并切换、放弃修改、取消，失败保留草稿。
- 视频 1、视频 2、视频 3 的默认地址分别通过 `client/.env` 中的 `VITE_PREVIEW_VIDEO_1_URL`、`VITE_PREVIEW_VIDEO_2_URL`、`VITE_PREVIEW_VIDEO_3_URL` 配置，均支持 HTTP(S) 直链与 public 资源路径；未配置或空值使用对应内置示例（`client/public/preview/sample-1.mp4`～`sample-3.mp4`，正好 10 秒的 1080×1920、30fps、无音轨片段，随客户端打包；桌面端经预览媒体服务以 HTTP 地址播放，浏览器首次读取时整段读入内存、以 blob URL 播放并在应用存活期间复用，弹窗仍显示示例的资源地址，读取失败下次重试）。修改后重启 Vite，生产使用需重新构建。「加载预览视频」打开弹窗设置视频 1、视频 2、视频 3 的 URL 或本地文件（`features/templates/localVideos.ts`，每个不超过 512 MiB，不上传服务端；桌面由 Tauri `preview_video_list/write/remove` 保存在应用数据目录 `data/preview_videos/`，播放用预览媒体服务按数据文件名提供的 HTTP 地址，视频字节不经 IPC 读回页面，重启后登记各槽位地址并优先于默认地址，恢复时以 HEAD 请求确认可读，单个文件不可读时该槽位回退默认地址；写入与删除使用同一短暂重试的独占目录锁，数据文件唯一命名、元数据替换为提交点，中断或失败不丢失旧视频，加载中任一槽位保存失败则已完成的槽位回滚（替换或删除读回的视频前先从媒体服务读回原视频，读不到就不开始提交），保存期间弹窗不可关闭；改用 URL 即删除该槽位的本机副本；浏览器只以页面内存的 blob URL 播放，刷新恢复默认），读取全部真实时长和尺寸并通过时间校验后一起更新、本地文件保存成功后才替换来源；失败保留当前来源并标明视频编号，关闭或取消终止读取。URL 来源各取前十秒、不足十秒时使用完整区间，本地文件与内置示例使用完整时长（`previewVideos` 按 blob URL 或媒体服务的本机视频地址区分，内置示例正好十秒），保留当前排列，画布固定为 1080×1920，不随视频变化。视频信息独立于模板保存，独立视频元素在完成、失败、取消和卸载时清理。
- 模板预览画布与 SDK 场景固定为成片的 1080×1920（`timeline.ts` 的 `PREVIEW_CANVAS`，与服务端 `composition_width/height` 默认值及 AI 资产画布一致），不随用户换的预览视频变化；视频与正式合成一样按 Contain 等比放入、留白用 `Background/Blur`（Radius 0.1）模糊填充，比例与画布相同时没有留白、不加模糊，转场补帧沿用所属视频的留白填充。默认示例也读取真实尺寸并保留十秒区间。标题、字幕和气泡字号支持 12～300 的整数，预览与云端保存统一校验；字号按画布像素计算，标题和字幕预览保留原文，不添加自动换行。显示区域同时受可用宽度与窗口高度的 48% 限制，等比例呈现完整画面。SDK 在独立 iframe 初始化，通过 `maxCanvasConfig` 设置尺寸，视频尺寸变化时重新初始化并清理旧播放器。每次应用时间线后 `TemplatePreview` 用 `waitForCanPlay` 等 SDK 发出 canplay 才显示“预览已就绪”并改由 SDK 推进播放位置（此前由前端时钟推进）：`setTimeline` 返回时 SDK 还没建好播放节点、内部时长仍是 0，这时播放会在 0 秒立即结束；计时从 `setTimeline` 完成后开始，等满 60 秒（`CAN_PLAY_TIMEOUT_MS`；网络或设备慢时 SDK 加载素材与字体可能要十几秒）仍没有 canplay 才切换 `BasicVideoPreview` 基础视频并停用 IMS 文字与特效，不能把超时当成就绪。`loadSDK` 在创建播放器前把 SDK 内置 Konva 的全局 `pixelRatio` 固定为 1：画布与场景同为视频原尺寸，不再按屏幕缩放倍数放大（2 倍屏上原为 2160×3840），坐标与字号不变。
- 顶部标题对象的 `tracks[].editor` 保存 `titleKeyword`、四个可组合的局部样式布尔选项 `titleKeywordBold`、`titleKeywordItalic`、`titleKeywordUnderline`、`titleKeywordStrikeout`、可选的 `titleKeywordColor` 与 `titleKeywordSize`；预览在关键词为空时从示例标题首段连续文字选取前两个字，已有指定关键词继续应用；修改示例标题时清除指定关键词。视频合成调用切片时传入请求 `title`，仅使用切片快照返回的 `title_keyword`；字段缺失或为空时不强调标题关键词，不回退模板词或前两个字，旧快照同样适用。无声纯素材有非空标题时调用仅标题提词并要求切片模型配置，仍跳过 ASR、正文切片与匹配；空标题不调用模型。底部字幕对象独立保存 `subtitleKeywordBold`、`subtitleKeywordItalic`、`subtitleKeywordUnderline`、`subtitleKeywordStrikeout`、`subtitleKeywordColor` 与 `subtitleKeywordSize`；预览使用示例字幕的首个词语，合成使用每段切片的 `keyword`。颜色为空字符串或 `#RRGGBB`，局部字号为 0（沿用原字号）或 12～300 的整数；只标记首次出现的位置，颜色按 IMS 要求转换为 BGR，字号通过 IMS `\fs` 设置并恢复；其他对象不得启用对应样式，已有模板缺少新字段时读取默认值。 视频合成按气泡对象自身时间区间显示其 `bubbleText` 示例文字一次，不使用切片关键词；有气泡对象但未选气泡样式时仍显示文字，无气泡对象则不生成。关键词继续通过标题和字幕的局部样式强调。
- 预览保留阿里云 SDK 5.2.2；SDK 渲染引擎加载 wasm 后请求一次 `vpp-license-proxy.aliyuncs.com/getWebCert`，等到回应才初始化：空域名的请求只得到不含证书的 JSON，引擎随后按 localhost 条件无证书初始化（保留水印），授权结果并不决定能否播放；但网络慢时第一次播放要等它，请求失败、超时或回应不是 JSON 时 SDK 还会把渲染引擎标为初始化失败且不再重试（视频层黑屏，点播放时间不走，只有拖动时字幕层更新）。所以 `sdk.ts` 的 `deferLicenseRequest` 在 SDK 加载前接管播放器窗口的 fetch，把授权变成后台操作：SDK 立即拿到同样的无证书结果（空 JSON），不等网络就初始化；真实请求照常在后台发出，出错、非 2xx、回应不是 JSON 或 10 秒没有回应时只写调试日志警告（播放器停用或卸载后不记），授权结果不触发降级，停用时恢复原 fetch。收到 SDK `renderError`、播放器初始化失败、生成转场画面或载入时间线失败、载入时间线 60 秒没有完成（这时 canplay 的计时还没开始）、60 秒仍没有 canplay、10 秒没有确认定位，或 IMS 播放中 10 秒时间没有前进（`STALL_TIMEOUT_MS`；如系统 WebKitGTK 里 SDK 对 blob 视频一直等不到 canplaythrough，报告在播放却定格）时，`TemplatePreview` 切换 `BasicVideoPreview` 并在预览下方说明原因：每段一个预加载的静音 `<video>`，按解析出的片段顺序与段长播放，由同一套播放按钮、从头重播、进度条与时间轴控制，播放时逐帧把全局时间交给 AI 资产叠加层。降级只停用 IMS 侧的文字、转场、滤镜、VFX 与模糊留白；时间轴的对象与视频行（SDK 未加载时用随包效果目录生成）、文字选择框和 AI 资产都照常可用。画布固定为 `PREVIEW_CANVAS`，挂载时就显示画布与 AI 资产叠加层，不等 SDK 页面、脚本或时间线；预览不再下载 IMS 测量字体（标题字幕预览去掉自动换行后已无人使用，下载失败却会导致降级）。客户端测试环境不加载外部脚本与样式表（happy-dom 按加载成功派发 load），`template-preview.test.tsx` 在播放器页面挂上 SDK 替身检查 IMS 各阶段。只有 canplay 后正常 SDK 路径才标为 IMS 预览就绪。预览标题栏的「刷新预览」不随加载状态禁用（卡在载入时间线时也可用），点击后销毁当前播放器并按当前草稿重新初始化。
- 资产的代码固定，模板里每次摆放可以覆盖发布的可编辑参数并设置宿主变换：云端模板编辑左侧「Remotion 资产」从 `GET /api/sprites` 目录按分类添加（目录卡片与「特效资产」共用 `AssetBrowser`（搜索、卡片网格、分批显示），分类切换沿用 Remotion 自己的分类，不并入 IMS 特效列表；封面不新增服务端产物，由 `SpriteCover` 在前端定格：卡片进入视口才加载该资产的 `GET /api/sprites/{id}/preview?sync=1&fonts=host` 隔离播放器（字体同样由宿主页面转交），经 `imv-preview-sync` 定位到资产时长 50% 处作静止封面，悬停或聚焦时依次轮播 20%、80% 处（要求减少动态效果时不轮播），离开视口即卸载；旧版本不支持 `sync` 的资产显示「暂无封面」，预览页报错或 15 秒未就绪显示「封面加载失败」），右侧列出名称、时间与是否调整过参数，点选后设置参数与位置，并可移除；在预览下方时间轴按所占对象并入对应行，默认时长为资产的预览长度（`preview_frames / fps`），字效跟随所作用的文字对象，超出模板时长的部分截短显示。摆放（Remotion 片段）是云端模板 `tracks` 里的 `remotion` 轨道，随模板在同一次 `POST /template` 里原子保存（要么都成功、要么都不写入），模板保存之后没有单独的片段保存步骤；旧版的 `style_sprite_bindings` 表与 `GET/POST /api/sprites/styles/{style_id}` 已删除，其中的片段不再读取、不迁移，需要在模板里重新添加。同一资产可以重复添加，每次是独立的摆放（轨道 ID 不同）；客户端写入 seconds 起点、以发布预览长度初始化的摆放时长和这次摆放的覆盖，不带作用对象。保存时 `sprite_id` 必须是已发布的资产且画布一致，否则 422 并保留未保存的修改，列表对目录里找不到的资产提示保存前移除；添加时客户端就拒绝与已添加片段画布（宽×高、帧率）不同的资产并说明两边画布，目录里显示各资产画布；保存模板必须保留标题和字幕各一个，允许空效果列表。SDK 本身不渲染 Remotion 资产：预览画面上另叠透明的隔离 Remotion 播放器（`GET /api/sprites/{id}/preview?overlay=true&sync=1&fonts=host`）。只为当前时间附近的片段挂载播放器（片段开始前 3 秒到结束后 1 秒；已挂载的前后再多保留 2 秒，来回拖动游标不反复重载），离开后卸载，回来时重新握手。字体由模板编辑页经 `GET /api/sprites/fonts/{weight}`（`no-cache` 加 ETag，复用前向服务端确认）读取一次（换了服务地址后重新读取），应播放器的 `imv-preview-fonts-request` 以 `imv-preview-fonts` 转交；读取失败时回复 `fonts: null`，宿主 30 秒内没有回答也一样，播放器改走同级 `/fonts/{weight}`。这样做是因为沙箱页是不透明来源，浏览器不为它缓存请求。预览包首行协议 2 才支持转交，更早的副本在首次预览时按发布源码重建。播放器由 SDK 的播放时间经 `imv-preview-sync` 消息逐帧定位（消息带摆放的完整时长 `duration` 秒，0～120，新构建的预览包按它设置 Player 时长，组合 Sprite 按它排布，与总线渲染一致；更早的包忽略它、停在预览长度末帧），播放器自身不播放、无控制条；仅回报 `sync` 能力的预览包可叠加，回报 `host` 能力的包还会收到 `imv-preview-update`（这次摆放的参数覆盖与 `host.transform`），不回报的旧包按发布默认值显示并提示重新保存；保存到资产时若版本封存的包较旧，会用封存源码、默认参数和画布在隔离 worker 中重建副本（失败不阻止保存，只是无法叠加预览；重复保存同一资产会刷新旧副本：先暂存并记录新哈希再替换，更新失败时旧副本仍可用，再次保存即重试；相同版本与字段选择的并发保存轮流执行，只重建一次），仍无能力的资产保持隐藏并提示。
