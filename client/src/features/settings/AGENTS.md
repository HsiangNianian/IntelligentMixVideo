# 设置协作约定

适用于 `client/src/features/settings/`，补充根目录与 `client/` 的 `AGENTS.md`。插件增删、Debug 启动配置与 Agent / IMS 配置的完整说明见本目录 README，改动前先读。

## 目录与模式

- 设置目录来自后端 `GET /api/settings/plugins`，模块列表只取后端目录，本地保存的值不产生导航。公共设置层不执行业务。
- 普通模式只请求 `client_only=true` 的目录（声明 `scope: "client"` 的 Remotion Agent 与上海 IMS），不携带切片配置；Debug 展示各模块完整配置与启动端口。只有 `IMV_DEBUG` 精确等于 `true` 才开启 Debug，Vite 开发不自动开启。保存时保留未展示的 Debug 字段。
- 通用面板不依赖目录读取成功，动态表单依赖 Schema。公共层只支持扁平标量 Schema，保存前统一校验类型、必填、数值上下界与字符串长度/模式；空的可选数字省略，false 是有效值；不支持的结构明确报错，不伪装成可保存的表单。

## 编辑与保存

- 通用面板可编辑共享后端地址，保存到保留键 `$client.api_url`：新请求立即采用，已有会话连接要重启客户端才切换；桌面启动优先用保存的地址，未配置才启动内置服务或用默认地址。
- `$client` 由宿主按字段合并，通用表单只提交实际修改的字段。
- 模块导航值与通用面板隔离；切换保留草稿，关闭弹窗丢弃未保存的值。底部固定「取消 / 保存」：保存只提交当前页并保留弹窗，取消关闭弹窗、丢弃未保存的草稿，不撤销此前已保存的值。

## 本地存储

- 桌面 `local_settings` 按模块 ID 保存到 `data/settings/settings.json`（含明文密钥）。读改写全程持有目录文件锁，被占用时在 500 毫秒内短暂重试，仍被占用才报错让用户重试；命令在阻塞线程池执行，不占用界面线程；临时文件刷盘后再替换。重试是因为 flock 锁属于打开的文件描述，本进程其他线程创建子进程时，子进程在 exec 前会短暂继承刚释放的锁（见 `file_lock.rs`）。
- 浏览器只在页面内存里保存；移除设置入口时保留旧值。
- Debug 内置后端启动前从同一份 `settings.json` 加载声明的字段，按别名或环境前缀覆盖进程环境，不写 `.env`；新增的高级字段保存后重启客户端生效。端口用于实际回环监听，未保存时自动分配；路径留空用随包默认，相对路径以 `backend/` 为基准，不迁移数据。浏览器、手动启动与远程服务不走这条加载路径。

## 请求配置

- 切片请求（`features/segmentation/api.ts`）执行时读取本模块配置并带到 `POST /segmentations`，只影响本次调用；省略时兼容旧路径，HTTP 策略归服务端，错误不回显输入。
- Remotion 的能力查询、创建、消息与重试读取本地 `remotion_agent`，IMS 提交与查询读取 `ims`，分别以 URI 编码的 JSON 请求头 `X-Remotion-Config`、`X-IMS-Config` 传递，不写进业务输入或 URL。解析复用类型与原有字段校验，未知字段忽略；不新增长度上限、Remotion URL 规则或消息/重试的就绪拦截。
- 后端按任务持有凭据，不改全局配置、不持久化密钥；IMS 只记录是否用了客户端配置。新的成功任务播放查询用持久化的 ZOS 地址，历史成功任务继续用请求的 IMS 凭据，不维护账号指纹或一致性检查。
- 任务与通知结束时清除凭据；缺少客户端 IMS 快照的任务以 `client_config_missing` 标为不可恢复、要求重新提交，缓存地址不可用时通知不再重试；Remotion 显式重试重新提供凭据。
- ASR、切片与素材匹配读取启动配置；侧边栏「操练场」通过固定样本调用视频合成，当前开放 IP口播。
