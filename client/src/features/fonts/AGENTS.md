# 字体组件协作约定

适用于 `client/src/features/fonts/`，补充根目录与 `client/` 的 `AGENTS.md`。

服务端字体库（`remotion_fonts`、上传接口、渲染沙箱字体）见 `server/src/server/remotion_templates/AGENTS.md`；IMS 模板字体目录见 `server/src/server/template/AGENTS.md`。

- IMS 与 Remotion 字体选择共用 `features/fonts/FontSelect.tsx`（搜索、字形预览、选中状态与附加操作）及 `FontName.tsx`（透明预览条按主题文字色显示）。`TemplateFontPicker` 使用上述十一种字体和随包 PNG，图片由 `client/scripts/generate-font-previews.mjs` 按 SDK 5.2.2 字体目录、实际字体文件和共享中文名称绘制；浏览选项无需联网。Remotion 的 `FontPicker` 提供实时字体库与上传操作，`FontLibrary` 也使用相同名称展示。预览条按文字实际宽度绘制，保持在 640×64 以内。真实浏览器回归及生成方式见客户端 README。
- 左侧导航「工作空间」组有「字体库」页面（`features/fonts/FontLibrary`，只在当前页签挂载、每次打开重新读取）：卡片展示库内全部字体卡片（预览条、家族名、风格、来源、已有字形、大小），点击打开字体详情（`FontDetails`：四个字形各自的预览条、字重、大小与 SHA-256，缺少的标为未上传，以及家族名、来源与许可证；点击已有的字形在对话框里打开它的字样 `FontSpecimen`：浏览器经 `file_url` 读取该字形的字体文件、以临时家族名注册为 `FontFace`，排出标题、字母数字、中文与可改示例句的字号阶梯，离开时移除；系统默认字体的文件是服务端安装的常规字重，同样经 `GET /api/templates/fonts/{id}` 提供，本机没有安装时为 null、不打开字样），可按名称或风格搜索，也可在页面上传字体，下拉选择器与该页面共用 `useFonts`（上传前按 SHA-256 在已读到的字体库里查找，已有同一个文件就直接选用、不再上传；修复前的原文件已登记时也不上传修复版，避免同一字体出现两张卡片；请求失败后重新读取字体库，按摘要找到即视为已在库里，因为超时或断线时服务端可能已经登记；服务端回答 200 时提示「字体已在字体库里」而不是「已添加」；不在安全上下文的网页没有摘要能力，只能依赖服务端的幂等回答）。上传前浏览器先做目录级修复（`features/fonts/repair.ts`：只在目录里确实有长度为 0 的可选表时重写，删除这些表、按标签重排表目录并补正二分查找字段、按实际数据重算各表校验和与 `head` 的 checkSumAdjustment、裁掉尾部不属于任何表的字节，字形、name、cmap 等表的数据不动，修复幂等；没有零长度表时保持原字节，避免仅因头部、校验和或尾部字节不整齐就改变摘要），摘要、预览条与上传都用修复后的字节，按内容去重与之后渲染沙箱读到的文件一致；目录或表超出文件末尾、表和表目录或两张非空表重叠、必需表为空、没有可用的轮廓表、`loca` 的偏移不是从 0 开始递增或与 `glyf` 不自洽时拒绝并说明是哪张表，修复后浏览器仍解不开时说明浏览器无法解码，两种都不发上传请求；修复过文件的成功提示写明修了什么。后端不参与修复，仍只读取 name 表。前端 `ParameterControl` 对名为 `fontFamily` 的参数使用 `features/fonts/FontPicker`：读取实时字体库，选项用服务端预览条（CSS mask 着色）展示，可搜索，底部可上传自己的字体并立即选中，聊天参数面板与模板编辑的「外观与位置」共用。
